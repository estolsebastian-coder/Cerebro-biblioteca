Configurar los ODBC del Sistema SPSuite 3.0

El objetivo de este documento es explicar cómo seleccionar una base de datos para poder usarla con el
SP.

Pasos
\1. Ingresar a Panel de Control
\2. En función del sistema operativo que estemos utilizando tenemos que ingresar a:
Win2000 / XP: Herramientas Administrativas\Orígenes de datos (ODBC)
Win98: Fuentes de datos (ODBC)
Win95: Orígenes de Datos (ODBC 32 bits)
\3. Accederemos a una ventana como la siguiente:

<!-- p. 2 -->

\4. Una vez hecho doble clic sobre SPSuite aparecerá una pantalla como la siguiente

\5. Luego presionamos el botón seleccionar y aparecerá una pantalla como la siguiente

• En el cuadro seleccionado con el circulo verde navegamos hasta el lugar donde pusimos la base,
por defecto estará en c:\SISTEMA\NILENSUR\SP30\Base, una vez llegado a esa ubicación, la
misma aparecerá en el cuadro seleccionado con el circulo rojo en este caso la base se llama
GX_Data.mdb pero en el caso tuyo se llamará Sp.mdb, la seleccionamos (doble click).
• En el caso de que la base esté en otra máquina se deberá navegar hasta la carpeta compartida en
donde se encuentra la base.
