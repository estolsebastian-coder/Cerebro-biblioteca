TIP 01 - Como calcular el cortante basal de un edificio (La fuerza
cortante total que actúa en el edificio) y como calcular los
cortantes de cada entrepiso o nivel.

<!-- p. 2 -->

I.- ASIGNAR GRUPOS
Primero, se seleccionan todas las columnas del nivel en donde se quiere conocer el cortante
debido a las fuerzas sismicas, seleccionando tambien todos los nodos inferiores de las columnas,
tal y como se muestra en la siguiente figura, haciendo notar que se debe de hacer esto para todos
los planos, hasta seleccionar todas las columnas de ese nivel.

Despues de debe de crear un grupo, desde el comando "ASSIGN / GROUP NAME..."

En este caso se Crea el grupo llamado BASE, y de manera similar se hace esto para los demás
niveles o entrepisos

II.- Después de que ya se corrio el modelo, se deben de seleccionar los casos de carga para los
que queremos ver resultados, haciendo clic en el icono ( O seleccionar del Menu: "DISPLAY
/ SET OUTPUT TABLE MODE" ) en la siguiente figura, y en este caso seleccionamos los casos
de carga de sismo en dirección X y en dirección Y para saber cual es el cortante en la base que
nos da el modelo, ya que el sismo de introdujo por espectro de diseño, y queremos saber que
cortante nos arroja.

III.- Por ultimo le pedimos al programa que nos de la suma de fuerzas del grupo que creamos
anteriormente, por medio del comando "DISPLAY / SHOW GROUP JOINT FORCE SUMS...", y
escogemos el Grupo BASE que hicimos anteriormente, y como se ve en la siguiente figura,
obtenemos el cortante total FX y FY, que en este caso es de 654.218 Toneladas para el sismo en
X, y de 602.778 Tonenalas para el sismo en Y. De manera similar se puede obtener el cortante
para cada entrepiso.
